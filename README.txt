Алмаштирилади:
crm/src/pages/AppraisalsPage.jsx

Янги логика:
1) Янги заявкада аввал «Кўриш / ўрганиш».
2) Деталда мижоз, гаров мулки, изоҳ, ҳужжатлар ва расмлар кўринади.
3) Ҳужжат/расмни кўриш ва юклаб олиш мумкин.
4) Детал очилгандан кейингина «Заявкани қабул қилиш» чиқади.
5) Қабул қилингач, детал ичида «Ишни бошлаш» чиқади.
6) Иш жараёнига ўтгандан кейингина ҳисобот формаси очилади.
7) PDF юкланганда backend мавжуд логикаси REPORT_READY ҳолатига ўтказади.
