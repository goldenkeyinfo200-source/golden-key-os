- Икки колонкали компакт кўриниш қўшилди.
- Баҳолаш заявкалари қисмига тегилмади.
- Баҳоловчининг «Кўриш / ўрганиш → Қабул қилиш → Ишни бошлаш → PDF ҳисобот» жараёни сақланди.
