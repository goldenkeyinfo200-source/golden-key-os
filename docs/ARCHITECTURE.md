# Golden Key OS — v0.1 архитектура

- Мурожаат қилувчи ва кредит олувчи алоҳида сақланади.
- Бир ишда бир нечта кредит олувчи номзоди бўлиши мумкин.
- Шартнома фақат банк маъқуллаган кредит олувчи билан тузилади.
- Банк тасдиғидан кейин иш ижрочига бириктирилади.
- Ижрочи кредит чиқиши, мижоз маблағни олиши ва хизмат ҳақи тўлангунига қадар масъул.
- Барча ҳаракатлар Audit Log'га ёзилади.
- Якунланган ишлар архивга ўтади.
